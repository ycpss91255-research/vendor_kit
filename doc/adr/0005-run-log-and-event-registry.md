# ADR-0005：機器可讀的輸出只走執行紀錄，事件名由註冊表封閉

> Serves: 機制（服務不變量 4），不建立不變量——本檔記錄執行紀錄的機器可讀格式、事件註冊表的真本位置與比對方式，以及「未註冊事件名 = 實作錯誤」的處置，是[不變量 4「永不靜默失敗」](../decisions/review/02_invariants.md#4-永不靜默失敗)裡「執行紀錄不可關閉」那一段的實現機制。

- **Status:** Accepted

## Context

VK 站在每個 repo `just` 指令的最前面。它靜默失敗，錯誤就傳到每個 repo 而沒人知道，所以「執行紀錄不可關閉」被寫成不變量（見[第 4 條](../decisions/review/02_invariants.md#4-永不靜默失敗)）。剩下的是機制問題：紀錄要長成什麼樣、事件名由誰決定、兩個實作怎麼對齊。

寫紀錄的不是一個實作，是兩個。啟動器在主機上以 POSIX sh 執行，引擎在容器內執行，兩邊各寫自己那一段事件。連零寫入的那條救援路徑也已經寫過紀錄：判定版本組合不合之前，啟動器與引擎的開始事件都進去了。事件名要是各邊自己長出來，同一件事在兩邊會有兩個名字，而讀紀錄的人不會發現。

另一件是機器要讀的輸出。後續檢查（`sync`、CI 檢查腳本、下一個可寫 recipe）必須看得出上一次執行做到哪裡。這件事若靠解析給人看的訊息，訊息措辭改一次，讀的那一端就靜默壞掉，正好是不變量 4 要擋的東西。

## Decision

### 1. 機器可讀的輸出只有紀錄與 resolve 回傳

機器可讀的輸出走執行紀錄 JSONL 與 `vk-resolve/<P>` 文法，不開 `--porcelain`。

給人看的訊息不承擔機器介面。要程式判讀 VK 做了什麼，讀 JSONL 的執行紀錄；啟動器與引擎之間那一段走 `vk-resolve/<P>`。

### 2. 事件名由註冊表封閉

事件註冊表 `log-events.txt` 是執行紀錄事件名的有限集合。啟動器與引擎寫紀錄前先對表，未註冊的事件名當實作錯誤處理（FATAL，不是使用者的錯）。CI 另以靜態檢查擋原始碼裡未註冊的事件名。

執行期對表擋動態組出來的事件名，靜態檢查擋寫死在原始碼裡的。兩層都要，因為兩邊各自看不到對方那一類。

### 3. 真本在引擎，啟動器只帶子集

註冊表真本放引擎 image，啟動器的 `log.sh` 內嵌一份啟動器事件白名單，release CI 驗「內嵌清單 ⊆ 真本」。

擁有者只有一個：引擎 image 裡的 `log-events.txt`。`log.sh` 內嵌的那份是啟動器側的子集副本，不是第二份真相：它只准少，不准多，這條由 release CI 的子集檢查擋。啟動器要內嵌是因為它在容器起來之前就開始寫紀錄，那時讀不到真本。

## Consequences

- 讀 VK 執行結果只有兩個介面：執行紀錄與 `vk-resolve/<P>`。人讀的訊息改措辭不會弄壞任何讀取端。
- 事件名成為對外契約的一部分。新增一個事件要改引擎 image 裡的真本；若是啟動器事件，`log.sh` 的內嵌清單也要一起改。
- `log.sh` 是薄殼檔，改它會讓既有 repo 的薄殼與引擎不符，那些 repo 要先 `upgrade vendor_kit`。所以啟動器事件不是隨手加的東西。
- 不開 `--porcelain` 的代價：想在同一次呼叫的 stdout 拿到結構化輸出的人拿不到，得去讀紀錄檔。
- 別的 ADR 要精確引用某個事件名或某段紀錄欄位時，引本檔第 2 節與真本，不各自複述一份清單。
- 需要同步更新：`doc/decisions/review/02_invariants.md` 第 4 條的「建立或服務它的 ADR」行加上 ADR-0005。
- 驗收：release CI 的「內嵌清單 ⊆ 真本」檢查，加上原始碼的靜態檢查。執行期對表由引擎與啟動器各自的測試涵蓋。

## Alternatives

- **開 `--porcelain`。** 會滿足「一次呼叫就在 stdout 拿到結構化輸出」，代價是多一個機器可讀介面，而且它是人讀訊息的平行版本：同一件事改一次要改兩處，遲早不同步。執行紀錄已經涵蓋這個用途。
- **事件名開放，各實作要寫什麼就寫什麼。** 實作最省事，但讀紀錄的那一端永遠不知道會遇到什麼名字，打錯字的事件名不會有人發現，就是不變量 4 要擋的那種靜默。
- **未註冊的事件名只 warn，照樣寫進紀錄。** 不變量 4 要求 warn 要指名對象並列出下一步，而未註冊只可能是實作錯誤，使用者沒有下一步可做。降成 warn 只會讓它被吞掉。
- **註冊表真本放薄殼、隨 repo 進 git。** 啟動器就不必內嵌子集，代價是真本散成每個 repo 一份，引擎升版要去改每個 repo 的檔，擁有者從一個變成 N 個（違反 [P5：一條規則一個擁有者](../decisions/design_principles.md#p5-一條規則一個擁有者)）。
- **只靠 CI 靜態檢查，執行期不對表。** 便宜，但靜態檢查看不到執行期組出來的事件名，那一類會直接漏過去。
