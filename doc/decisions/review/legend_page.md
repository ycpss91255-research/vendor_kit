# 主圖「00 圖例與記法」頁內容清單

> 2026-09-20 定案。供之後畫圖用：這一頁放在主圖最前面，是所有頁的記法與顏色正本；其他頁不再各自解釋顏色與符號。

## 1. 顏色（六種）

| 顏色 | 意思 |
|---|---|
| 藍 | 引擎做 |
| 白 | 啟動器做 |
| 綠 | 結束碼 0 |
| 橙 | 需人處理（結束碼 1 或 3 且附指令；衝突 2 亦同） |
| 紅 | 失敗（拉不到、寫不進、驗證不過；結束碼 1） |
| 白虛線橢圓 | 來自其他頁的節點 |

## 2. 結束寫法

- 「→ 1：X」= 以結束碼 1 結束並印出 X。
- 「→ 0」= 以結束碼 0 結束。
- 「→ 2」「→ 3」同理。

## 3. 語法記法

| 記法 | 意思 |
|---|---|
| `<x>` | 必填佔位符 |
| `[x]` | 可省略 |
| `[@<tag>]` | 可省略的版本後綴，緊接 repo 名（`<repo>@<tag>`） |
| `-x <值>`／`--long <值>` | 短／長選項等價；只有常用的才有短的 |
| `-y` | 不帶值的開關 |
| `a／b` | 二選一 |

常用選項一句話：

- `-p <dir>`：把工具指到本機目錄。
- `-i <tag>`：把引擎指到本機 image。
- `--exit-code`：有新版時以結束碼 2 回報。
- `-y`：省略詢問，視同回答「是」。

## 4. 佔位符

| 佔位符 | 意思 |
|---|---|
| `<repo>` | 下游 repo 名 |
| `<ns>` | 工具的 just 命名空間 |
| `<tag>` | image 版本名 |
| `<digest>` | image 內容指紋 `sha256:…` |
| `<verb>` | 動詞名 |
| `<id>` | 一次執行的交易 id |

## 5. 其他

- 動詞寫法：小寫原文，前面省略 `just vendor_kit`。
- 三方一律寫全名：下游開發者／下游使用者／VK。
- 例子一律用 `<repo>`，不寫具體工具名。
