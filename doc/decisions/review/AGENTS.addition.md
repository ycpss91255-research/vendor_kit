## 文件與圖的工作約定

### 審閱順序

- 由外而內、一頁一頁審：先審第 0 頁「圖例與記法」與「名詞與縮寫」，再審第 1 頁，依序往內。
- 頁 N 只用第 0 頁與前面各頁已定義的詞；不得前引（不得引用頁 N 之後才出現的內容）。
- 各頁的名詞表只列該頁特有的詞，不重複第 0 頁與前面各頁。

### 頁面與記法

- 頁名帶序號（`00 圖例與記法`、`00 名詞與縮寫`、`01 不變量與角色`…），文中引用頁時寫序號。
- 記法（`<x>`、`[x]`、`[@<tag>]`、`-x <值>`／`--long <值>`、`-y`、`a／b`、「→ 1：X」）與顏色（藍／白／綠／橙／紅／白虛線橢圓）一律以主圖第 0 頁「圖例與記法」為準，其他頁與文件不得另立一套。
- 出處標記（條號 → 來源檔與章節）放各頁文末附錄，不夾在正文。
- 例子一律用 `<repo>`，不用具體工具名（不寫 base、agent_harness）。

### 資料放哪裡

- 決策（取捨與理由）進 `doc/adr/`，不進 drawio。
- 名詞（是什麼）進 `CONTEXT.md`，不進 spec issue。
- 規則（審閱規則、寫法約定）進 `AGENTS.md` 與主圖第 0 頁，不進 `CONTEXT.md`；`CONTEXT.md` 只放 glossary。
- 規格（表格、選項、訊息、流程細節）進 issue。
- 圖只留架構／流程／狀態機／契約圖／目錄樹。
