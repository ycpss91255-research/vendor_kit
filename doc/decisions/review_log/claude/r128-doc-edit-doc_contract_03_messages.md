10. **位置**：03:57-80（代碼表，慣例對照）
    **問題**：沒有違反慣例，記錄如下。

    - `--exit-code` 查到差異回 `1`：符合 `git diff --exit-code`。

    - 回答「否」回 `0`：跟 apt-get（Abort 回 `1`）不同，但有 #115 的理由。

    **建議**：不用改。
