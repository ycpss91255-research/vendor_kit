## 建議

1. **位置**：03:34（「stderr 只放……」）對照 03:35。
   **問題**：35 行把 `vendor_kit <版本>` 寫成 stderr 第一行，但 34 行列舉 stderr 可以放的內容時只列了「診斷及其續行、詢問文字、用法錯誤後附的用法」，版本行不在裡面。兩行在同一段互相矛盾。
