# r134 doc-edit 審查：GLOSSARY.md

範圍：`diff -u doc/decisions/_backup/GLOSSARY.pre_r134.md GLOSSARY.md`。這一輪只改了第 205 行「失敗」的定義。
已定案核對：逐條對照 map #78 的「Decisions so far」（#79～#103）以及 #114、#117、#122、#123，沒有違反任何一條。01 的承諾沒變，02 第 4 條沒有被削弱，03／04 的對外介面也沒有 ask 以外的改動。

## 必改

1. **位置**：GLOSSARY.md 第 205 行「**失敗**」
   - **問題**：寫的是「不承諾有可直接執行的修法」，跟 03 和定案用的字不一樣。03_messages.md 第 63 行是「失敗不承諾可執行的修法，但可以附一般建議」，#123 `[claude] 定案` 第 3 點與 ask 第 1 點也是「不承諾可執行的修法，但可以附一般建議」。GLOSSARY 多了「有」「直接」三個字，「可直接執行」比「可執行」窄，同一個名詞在名詞表和 03 的範圍就不一樣了。
   - **建議**：改成「診斷的處置屬性，表示這次執行沒有做完；不承諾可執行的修法，但可以附一般建議。」
   - **證據**：GLOSSARY.md:205；doc/contract/03_messages.md:63；#123 最後一則 `[claude] 定案` 第 3 點。

## 建議

1. **位置**：GLOSSARY.md 第 205 行「**失敗**」
   - **問題**：舊定義的「只能說明原因」整句刪了，新定義沒提失敗也要說明原因。02 第 4 條要求「不是成功的結果都要說出原因」。新定義沒有違反這條，但第一次讀的人會以為失敗只要可以附建議就好，不用講原因。
   - **建議**：改成「……沒有做完，要說明原因；不承諾可執行的修法，但可以附一般建議。」
   - **證據**：GLOSSARY.md:205；doc/decisions/_backup/GLOSSARY.pre_r134.md:205；doc/contract/02_invariants.md 第 4 條「不是成功的結果都要說出原因」。

2. **位置**：GLOSSARY.md 第 202 行「**需人處理**」
   - **問題**：#123 定了判準，`next_step` 必須是「不用使用者自行代換就能執行的單一指令」才能標需人處理。名詞表只寫「可直接複製的下一步指令」，沒寫「單一指令」，也沒寫「不用使用者自行代換」。VK0001、VK0006、VK0007 這一輪改成失敗，靠的就是這個判準。名詞表沒寫的話，以後再有人加代碼時，只能去翻 issue 才知道怎麼判斷。
   - **建議**：改成「必須附上一條不用使用者自行代換、可直接複製執行的下一步指令」。03 第 75 行 `next_step` 的說明也要同步，這一點請跨檔一致性那一步一起看。
   - **證據**：GLOSSARY.md:202；doc/contract/03_messages.md:75；#123 `[claude] 定案` 第 2 點。

3. **位置**：GLOSSARY.md 第 214 行「**結束碼**」的「`3`（fatal）……這類診斷也可能是需人處理」
   - **問題**：這一輪以前 fatal 全都是需人處理（VK0007、VK0008、VK0009）。這一輪 VK0007 改成失敗之後，fatal 兩種處置都有。「也可能是需人處理」現在讀起來像「通常不是需人處理」，沒把失敗也算進去。
   - **建議**：改成「`3`（fatal）只表示版本組合不合，處置可能是需人處理或失敗」。
   - **證據**：doc/contract/03_messages.csv VK0007（fatal、失敗）、VK0008 與 VK0009（fatal、需人處理）；GLOSSARY.md:214。

4. **位置**：GLOSSARY.md 第 202～205 行（需人處理、失敗）
   - **問題**：用法錯誤（VK0024～VK0027）的處置已定為留空（#123 定案第 4 點），但名詞表裡沒有一處寫到。新的失敗定義是「沒有做完；不承諾可執行的修法」，用法錯誤也完全符合，讀的人會把用法錯誤歸成失敗，跟 CSV 的留空對不上。
   - **建議**：在失敗定義後面補一句「用法錯誤不標處置」，或在結束碼條目的「包括用法錯誤」後面加「（不標處置）」。
   - **證據**：doc/contract/03_messages.csv VK0024～VK0027 的 disposition 是空的；doc/contract/03_messages.md:72；#123 `[claude] 定案` 第 4 點。
