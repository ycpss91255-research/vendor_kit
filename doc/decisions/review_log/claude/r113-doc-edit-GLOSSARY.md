# r113 doc-edit 審查：GLOSSARY.md

本輪 GLOSSARY.md 只改了「救援路徑」詞條（第 240 行）的最後一句：原本是「其他 recipe 的 `-h`／`--help` 不屬救援路徑。」，改成「本詞條不規定救援路徑以外 recipe 的 `-h`／`--help` 在版本組合不合時的行為。」

## 必改

無。

- 定案對照：跟第 23、26、27、28 條都沒有衝突。四種印用法呼叫、`just vendor_kit` 不帶指令的輸出（stderr、`2`）、沒有頂層 `-h`／`--version`，都照原樣保留（第 28 條；04:135-136）。救援路徑列的呼叫沒變，所以沒有削弱 02 不變量 4、10 或 ADR-0007:32。
- 跟其他檔一致：新句跟 ADR-0007:32（「架構階段再定（Q13）」）、04:134（「這一頁不定；一定能用的只有救援路徑列的那幾種」）、03:60（6-36 已刪「含其他 recipe 的 `-h`／`--help`」）說法一致。
- 連結、名詞：本輪沒有新增連結；新句用到的「救援路徑」「recipe」「版本組合」都是本檔已定義或已在用的詞，沒有 _Avoid_ 詞。

## 建議

1. 位置：GLOSSARY.md:240 最後一句。
   問題：「本詞條不規定…」只說不規定，沒說在哪裡定。ADR-0007:32 寫的是「架構階段再定（待討論佇列 Q13）」，第一次讀的人看不出這是還沒定，還是刻意留給實作。
   建議：改成「救援路徑以外 recipe 的 `-h`／`--help` 在版本組合不合時怎麼反應還沒定，架構階段再定（[待討論佇列](doc/decisions/review_log/discussion_queue.md) Q13）。」GLOSSARY 不是對外審閱頁，可以連到佇列。
   證據：ADR-0007:32；discussion_queue.md:155-161（Q13）。

2. 位置：GLOSSARY.md:240，跟 03_messages.md:60（6-36）一起看。
   問題：6-36 刪掉括號後仍寫「執行救援路徑以外的 recipe」回 `3`。`just vendor_kit add -h` 也算「執行救援路徑以外的 recipe」，所以還是可以讀成 `-h` 回 `3`，跟 GLOSSARY「不規定」、04:134「這一頁不定」的語氣不一致。要不要處理是 03 的事，但 GLOSSARY 的新句只有在 6-36 不被這樣讀的時候才成立。
   建議：本輪 ask 只要求刪掉結論，所以 GLOSSARY 不必動。03 的審查者判斷 6-36 需不需要排除 `-h`（例如寫「`-h`／`--help` 見 04」）；不排除的話，就在 Q13 裡記下這個讀法。
   證據：03_messages.md:60；04_interface.md:134；GLOSSARY.md:240。
