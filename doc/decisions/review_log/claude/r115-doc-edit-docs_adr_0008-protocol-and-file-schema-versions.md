# r115 審查：docs/adr/0008-protocol-and-file-schema-versions.md

審的是 r114（ebe85e3）的改動。`_backup/` 沒有 `pre_r115`，`git diff HEAD` 為空，這一輪工作區沒有再改這個檔。

已核對：
- 編號：第 29 行 6-19→M6、第 31 行 6-10→M4，跟 03 第 56、58 行的內容對得上；檔內沒有殘留 6-N。
- 錨點：不變量 4、7、10、P5、Q5、03 `#訊息` 都存在。
- 定案第 1～29 條：沒有違反。第 3 行與標題的改寫跟 02 第 94 行（第 4 條）一致，沒有放寬也沒有收緊。

## 必改

無。

## 建議

1. **位置**：第 3 行「救援路徑在版本組合不合時仍然可用，並照原有行為寫入」，對照第 31 行。
   **問題**：`upgrade --engine` 本身就是救援路徑（GLOSSARY.md 第 240 行）。引擎降版讀不回來時，第 31 行要它回 `3`、零寫入。第 3 行卻寫救援路徑「照原有行為寫入」，第一次看的人會以為兩句互相矛盾。邏輯上兩句相容：救援路徑自己判定出不合、以 `3` 結束時，照樣零寫入。但文中沒寫出來，r114 要消除的歧義在這裡還有一半。02 第 94 行也有同一個問題。
   **建議**：改成「救援路徑不因版本組合不合而被擋，照它本來的行為執行；救援路徑自己判定出不合、以 `3` 結束時（例如第 31 行的引擎降版），一樣零寫入。」
   **證據**：ADR-0008 第 3、31 行；GLOSSARY.md 第 240 行；02_invariants.md 第 94 行。

2. **位置**：第 3 行，不變量引用。
   **問題**：零寫入限縮後只引用了不變量 4。02 第 190 行（第 10 條）仍寫「版本組合不合必須……並以零寫入結束」，沒有限在「以 `3` 結束的那次執行」，也沒提救援路徑。第 3 行開頭又拿第 10 條當依據，兩條不變量的說法寬窄不同，本檔站在較窄的那邊。
   **建議**：本檔不必改。02 第 10 條第 190 行要補成「判定出不合的那次執行以零寫入結束」，或直接改成「零寫入的範圍見第 4 條」。在這之前，本檔第 3 行的零寫入句只連第 4 條即可，現況正是如此。這一條記下來，給 02 的審查對照用。
   **證據**：02_invariants.md 第 94、190 行；ADR-0008 第 3 行。

3. **位置**：第 3 行「救援路徑」。
   **問題**：這是本檔第一次出現「救援路徑」，沒有連結。救援路徑的清單與規則歸 ADR-0007 管（ADR-0007 第 32 行），本檔在這裡重述「照原有行為寫入」，等於同一條規則有兩個擁有者。這正是本檔第 8 行引用的設計原則 P5 要避免的事。
   **建議**：「救援路徑」連到 GLOSSARY 的詞條，或連到 ADR-0007。句子縮成「救援路徑不受這條零寫入限制，見 ADR-0007」。
   **證據**：ADR-0008 第 3、8 行；ADR-0007 第 32 行；GLOSSARY.md 第 239～240 行。

4. **位置**：第 3 行與第 31 行，零寫入的寫法。
   **問題**：第 3 行寫「不動 repo 檔與 VK 檔，執行紀錄例外」；第 29 行寫「除執行紀錄外，任何寫入之前」；第 31 行寫「零寫入；執行紀錄不算在零寫入內」。同一個概念在同一個檔裡有三種寫法。標題還用「零寫入」，第 3 行正文卻沒有出現這個詞，也沒有定義它。
   **建議**：第 3 行寫成「……的那次執行零寫入：不動 repo 檔與 VK 檔，只有執行紀錄例外」，跟 02 第 94 行逐字對齊。第 31 行的「執行紀錄不算在零寫入內（不變量 4）」刪掉，零寫入的定義已經在第 3 行。
   **證據**：ADR-0008 第 1、3、29、31 行；02_invariants.md 第 94 行。

5. **位置**：第 1 行標題。
   **問題**：「判定不合的執行零寫入回 3」少了斷句，一口氣讀下來很難分出主詞與兩個動作。
   **建議**：改成「介面版與檔案版分開計數；判定不合的那次執行零寫入、回 3」。
   **證據**：ADR-0008 第 1 行。

6. **位置**：第 3 行「照原有行為」。
   **問題**：02 第 94 行寫「照它本來的行為寫入」，本檔寫「照原有行為寫入」，同一件事用了兩種字面。另外救援路徑裡有幾種印用法呼叫根本不寫檔（GLOSSARY 第 240 行），「寫入」一詞並不涵蓋全部救援路徑。
   **建議**：跟 02 用同一句「照它本來的行為」，把「寫入」去掉，或併進第 1、3 條建議一起改。
   **證據**：ADR-0008 第 3 行；02_invariants.md 第 94 行；GLOSSARY.md 第 240 行。
