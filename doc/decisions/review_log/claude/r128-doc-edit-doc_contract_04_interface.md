慣例對照（沒有列為必改）：`-h` 印到 stdout、回 `0`（GNU Coding Standards `--help`）；用法錯誤印到 stderr、回 `2`（grep、diff、argparse）；`--exit-code` 有差異才回 `1`，不帶時回 `0`（`git diff --exit-code`）；`--engine[=<tag>]` 只收 `=` 形式（getopt_long 的 optional_argument）。以上都一致。先印錯誤再印用法跟 git 的順序相同，argparse 則相反，兩種都常見，不算偏離。警告回 `1`、回答「否」回 `0` 是 #117、#115 已定的決議，不列。
