# r113 審查：docs/adr/0008-protocol-and-file-schema-versions.md

逐條對照過「已定案」第 1～29 條：這一輪只在第 3、29、31 行補「執行紀錄不算在零寫入內」，沒有違反定案，也沒有改 01 的承諾、削弱 02 的不變量，或改 03／04 的介面。三個錨點都對得上：`#4-永不靜默失敗`、`#10-相容性與演進同一個-x-內不破壞x-變動才可能不相容且先公告`、Q5、P5。

## 必改

1. **位置**：第 29 行「檔案版高於本引擎，在任何寫入前回 `3`（訊息 6-19）；執行紀錄不算在零寫入內」
   - **問題**：前半句寫的是「在任何寫入前」，不是「零寫入」。補上的限定要說明的「零寫入」這個詞，這句裡根本沒出現，所以限定掛不上去。前半句照字面讀，跟不變量 4「任何副作用之前，必須先留下可追溯的執行紀錄」衝突：引擎讀檔判出 6-19 之前，執行紀錄已經寫了，並不是「任何寫入前」。
   - **建議**：改成「檔案版高於本引擎，除執行紀錄外，在任何寫入前回 `3`（訊息 6-19）」，或改成「……回 `3`（訊息 6-19）、零寫入；執行紀錄不算在零寫入內（不變量 4）」，讓限定有對象。
   - **證據**：ADR-0008 第 29 行；02_invariants.md 第 96 行（「任何副作用之前，必須先留下可追溯的執行紀錄」）、第 92 行；03_messages.md 第 57 行（6-19 也寫「在任何寫入之前結束」，同樣的問題）。

## 建議

1. **位置**：第 22 行「三個都看結束碼 `3` 與零寫入」
   - **問題**：這一輪在第 3、29、31 行都補了「執行紀錄不算在零寫入內」，只有驗收這句沒補。黑箱驗收要照字面驗「零寫入」的話，會把必須存在的執行紀錄當成失敗，跟不變量 4 對不上。
   - **建議**：改成「三個都看結束碼 `3`，以及除執行紀錄外零寫入」。這句不在 ask 列出的行號內，要改就在下一輪做。
   - **證據**：ADR-0008 第 22 行；02_invariants.md 第 92 行；ADR-0007 第 31 行。

2. **位置**：第 3、29、31 行
   - **問題**：同一句「執行紀錄不算在零寫入內（不變量 4）」在一份短 ADR 裡出現三次，還各帶一次連結，讀起來很囉嗦。第 3 行已經把這個例外講清楚了。ADR-0007 第 31 行也已經寫「這裡與不變量 10、ADR-0008 說的『零寫入』，依不變量 4 都不含執行紀錄」。
   - **建議**：第 3 行保留完整句與連結；第 29、31 行改成短寫「除執行紀錄外零寫入」，不再重複連結。
   - **證據**：ADR-0008 第 3、29、31 行；ADR-0007 第 31 行。

3. **位置**：用詞，第 3、29、31 行
   - **問題**：同一個例外，四處寫法各不相同。02 第 4 條寫「只有執行紀錄例外」，02 第 10 條寫「執行紀錄不算在內」，03 結束碼 3 與 6-10 寫「執行紀錄除外」「除執行紀錄外」，ADR-0008 寫「執行紀錄不算在零寫入內」。意思一樣，但寫法沒有統一。
   - **建議**：ADR-0008 改用 03 的「除執行紀錄外」，至少第 29、31 行要改。
   - **證據**：02_invariants.md 第 92、190 行；03_messages.md 第 24、55 行。

4. **位置**：跨檔 03 的 6-36（第 60 行）
   - **問題**：ADR-0008 與 ADR-0007 第 31 行都說 3 的情況「除執行紀錄外」不動檔，但 03 的 6-36 說明欄只寫「不動 repo 檔與 VK 檔」，沒有「執行紀錄除外」；6-19 的訊息本文也沒有 6-10 那句「除執行紀錄外，未修改任何檔」。ADR-0008 引用的訊息之間寫法不一致。這不是 ADR-0008 本身的錯，但會讓讀 ADR-0008 的人去對 03 時對不上。
   - **建議**：下一輪讓 03 的 6-19、6-36 跟 6-10 對齊。
   - **證據**：03_messages.md 第 55、57、60 行。

5. **額外重點（救援路徑與 -h）**：ADR-0008 沒有提到救援路徑或 `-h`，所以跟這項沒有衝突。GLOSSARY 第 240 行、ADR-0007 第 32 行、03 的 6-36 對救援路徑的列舉一致，也都沒有「其他 recipe 的 `-h` 回 3」這個結論，符合 Q13 留待架構階段。02 第 10 條補的限定只是對齊第 4 條，承諾本身沒變。
