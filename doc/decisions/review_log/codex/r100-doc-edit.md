## 必改

- **位置：`CONTEXT.md:396–398`，「救援路徑」**
  - **問題：** 定義仍過度概括，沒有準確反映 ADR-0007 修訂後的邊界。「那幾個 VK recipe」容易被理解成整個 `sync` 都是救援路徑；實際上只有 `install`、`upgrade --engine`、`sync` 的不符判定，以及四種確切的印用法呼叫可在版本組合不合時使用。其他 recipe 的 `-h`／`--help` 明確不屬救援路徑。
  - **建議：** 直接列出三條 recipe／判定及四種印用法形狀；至少把「`sync`」限縮為「`sync` 的版本不符判定」，不要只寫「那幾個」。
  - **出處：** ADR-0007「修訂（2026-09-30）」第 80–84 行，尤其第 82–83 行；`02_invariants.md` 第 146 行；issue #71 的 U5。

- **位置：`CONTEXT.md:193–195`，「image 引用」**
  - **問題：** 格式使用未定義的佔位符 `<名稱>`。名詞表只定義了 `<repo>`、`<ns>`；而 `<name>` 又在第 149 行列為 _Avoid_。讀者無法判斷 `<名稱>` 是 registry repository、工具名、image 名稱，還是 `<repo>`。
  - **建議：** 換成已定義且符合實際格式的詞，或新增明確的 image 名稱／repository 定義；不要留下第三種未定義佔位符。
  - **出處：** `CONTEXT.md` 第 146–149、160–166 行；`02_invariants.md` 第 89、107 行；ADR-0002 的版本鎖定行正規形決議。

- **位置：`CONTEXT.md:5`，對外文件導覽**
  - **問題：** 三個目標以反引號純文字呈現，不是超連結。路徑都存在，但不符合這份文件其餘目錄項目所採用的「有名稱、可點擊」形式。
  - **建議：** 改為具描述名稱的 Markdown 連結，例如「[專案目的與承諾](...)」「[不變量](...)」「[ADR](...)」。
  - **出處：** 實際路徑 `doc/decisions/review/01_purpose.md`、`doc/decisions/review/02_invariants.md`、`doc/adr/` 均存在；`01_purpose.md` 第 3 行也已示範具名連結格式。

## 建議

- **位置：`CONTEXT.md:396–398`，「救援路徑」**
  - **問題：** 句子同時塞入版本組合、可用 recipe、印用法呼叫三個概念；第一次閱讀的人仍不知道「能用」是否包含回傳非零。尤其 `just vendor_kit` 會印用法但以 `1` 結束。
  - **建議：** 分成兩句，明說「可用」是能可靠印出結果，不代表成功碼為 `0`；不帶指令的呼叫會以 `1` 結束。
  - **出處：** ADR-0007 第 80–83 行；`02_invariants.md` 第 247、268 行。

- **位置：`CONTEXT.md:400–402`，「契約」**
  - **問題：** 「不會隨意改變」太主觀，沒有帶出真正的演進規則；讀者可能理解成契約永遠不能改。
  - **建議：** 改成可驗證的說法：同一個 major 內維持相容，破壞性改動只能隨 major 變動並預先公告遷移步驟。
  - **出處：** `01_purpose.md` 第 75–83 行；`02_invariants.md` 第 308–324 行；ADR-0008。

- **位置：`CONTEXT.md:358–380`，「VK recipe 與用途」**
  - **問題：** `help` 已完整移除，這一段沒有再把它列為 recipe；但本段沒有提示說明入口現在是 `-h`／`--help`，讀者只能到不變量頁才知道替代方式。
  - **建議：** 若名詞表要讓 recipe 介面自足，可在段首加一句「說明使用 `-h`／`--help`；沒有 `help` recipe」。不要重新建立 `help` 詞條。
  - **出處：** issue #71 U5；`02_invariants.md` 第 247、266、268 行；ADR-0004 第 57–65 行。

- **位置：`CONTEXT.md:5` 及目錄第 11–101 行**
  - **問題：** 目錄中的 64 個實際 Markdown 連結都有可見名稱，且所有 `#term-*` 目標均存在；但第 5 行的三個主要跨文件引用不是連結，形成不一致。
  - **建議：** 只需補第 5 行；現有目錄 anchor 不必調整。
  - **出處：** `CONTEXT.md` 各 `<a id="term-*">` 均與目錄目標一一對應。

- **位置：`CONTEXT.md` 全文，_Avoid_ 檢查**
  - **問題：** 未發現定義正文誤用自身列出的 _Avoid_ 詞；命中都只出現在 `_Avoid_:` 清單本身。
  - **建議：** 無須修改。
  - **出處：** `_Avoid_` 位於第 114、119、144、149、158、183、214、219、228、233、242、303、314 行。

- **位置：`CONTEXT.md` 全文，`help` 殘留檢查**
  - **問題：** 名詞表內沒有任何 `help` 殘留，也沒有其他詞條把它當 recipe。引用文件中的舊文字只存在於 ADR-0004、ADR-0007 的歷史原文，兩份 ADR 都有 Accepted 修訂明確宣告舊文不再適用。
  - **建議：** 名詞表不需再刪；若要降低誤讀，可依前項補一句「沒有 `help` recipe」。
  - **出處：** ADR-0004 第 57–65 行；ADR-0007 第 75–84 行；`02_invariants.md` 第 247 行；issue #71。
