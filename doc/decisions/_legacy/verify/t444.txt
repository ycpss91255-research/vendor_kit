build-worker: add submodules input for repos with git submodule source
## Problem

`build-worker.yaml` uses `actions/checkout@v6` without `submodules: recursive`. Repos that depend on git submodules for source code (e.g. `omniverse_web_viewer` which has `src/` as a submodule pointing to NVIDIA's `web-viewer-sample`) fail with:

```
"/src/package.json": not found
```

The Dockerfile's `COPY src/ /app/` finds an empty directory because the submodule was not initialized during checkout.

## Proposed solution

Add an optional `submodules` input (default `false`) to `build-worker.yaml`:

```yaml
inputs:
  submodules:
    required: false
    type: string
    default: ""
    description: "Submodule checkout mode passed to actions/checkout (empty=off, 'true'=top-level, 'recursive'=nested)"
```

Then in the checkout step:

```yaml
- uses: actions/checkout@v6
  with:
    submodules: ${{ inputs.submodules }}
```

Callers opt in:

```yaml
uses: ycpss91255-docker/base/.github/workflows/build-worker.yaml@vX.Y.Z
with:
  image_name: omniverse_web_viewer
  submodules: recursive
```

## Affected repos

- `ycpss91255-docker/omniverse_web_viewer` — `src/` submodule (NVIDIA web-viewer-sample)
