fix(upgrade.sh): #399 idempotency regex false-positive on COPY script/*.sh /lint/script/
## Bug

`upgrade.sh` #399 idempotency check (line 334) uses:

```bash
grep -qE '^[[:space:]]*COPY[[:space:]]+script/\*\.sh[[:space:]]+/lint/' "${_dockerfile}"
```

This matches `COPY script/*.sh /lint/script/` because `/lint/` is a prefix of `/lint/script/`. Repos that have **both** a stale `COPY *.sh /lint/` **and** a separate `COPY script/*.sh /lint/script/` (e.g. for repo-specific helpers that need the `/lint/script/` path in tests) trigger a false-positive skip — the stale line is never patched.

## Observed on

`ycpss91255-docker/isaac` — Dockerfile had:
```dockerfile
COPY *.sh /lint/                  # stale (zero files post-v0.31.0)
COPY script/*.sh /lint/script/    # isaac tests expect /lint/script/init_isaac_dirs.sh
```

`upgrade.sh v0.34.1` matched line 2 and skipped the patch. CI smoke tests (`script_help.bats`, `display_env.bats`) failed because `/lint/build.sh` didn't exist.

Workaround applied in isaac PR #27: manual dual-COPY to both `/lint/` and `/lint/script/`.

## Fix

Anchor the regex to match only `/lint/` as the full destination (no trailing path component):

```bash
grep -qE '^[[:space:]]*COPY[[:space:]]+script/\*\.sh[[:space:]]+/lint/?[[:space:]]*$'
```

The `$` anchor + optional trailing `/` + optional whitespace ensures `/lint/script/` does not match.
